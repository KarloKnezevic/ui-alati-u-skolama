# Upit 16.4 · Kviz kao JSON prema zadanoj shemi

Poglavlje 16: Provjere, kvizovi i rubrike: vrednovanje za učenje
Alati: bilo koji opći asistent

Uglata mjesta [OVAKO] zamijenite svojim podacima. Ne upisujte osobne podatke učenika.

```text
Pretvori kviz u nastavku u JSON točno prema ovoj shemi. Vrati SAMO
JSON, u jednom bloku koda, bez ikakvog teksta prije ili poslije.
SHEMA:
{
  "naslov": tekst,
  "razred": tekst,
  "pitanja": [
    {
      "tekst": tekst pitanja,
      "ponudeni": [ponuđeni odgovori kao tekst],
      "tocan": redni broj točnog odgovora u "ponudeni", BROJI OD 0,
      "bodovi": broj,
      "objasnjenje": [jedna rečenica za svaki odgovor, ISTIM REDOM],
      "ishod": oznaka ishoda
    }
  ]
}
PRAVILA: samo ravni navodnici ("); razlomke piši kao 3/8; ne mijenjaj
tekst pitanja ni odgovora; ako nešto nedostaje, upiši "NEDOSTAJE".
KVIZ:
[ZALIJEPITE PROVJERENI KVIZ]
```
