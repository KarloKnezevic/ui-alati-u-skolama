# Upit 16.5 · Iz JSON-a u GIFT za Moodle (Loomen)

Poglavlje 16: Provjere, kvizovi i rubrike: vrednovanje za učenje
Alati: bilo koji opći asistent

Uglata mjesta [OVAKO] zamijenite svojim podacima. Ne upisujte osobne podatke učenika.

```text
Pretvori JSON kviza u format GIFT za uvoz u Moodle (Loomen).
PRAVILA:
- prvi redak: // i naslov kviza;
- svako pitanje počinje naslovom ::P1::, ::P2:: ...;
- točan je odgovor s rednim brojem iz "tocan" (broji od 0):
  ispred njega =, ispred netočnih ~;
- iza svakog odgovora # i rečenica iz "objasnjenje", istim redom;
- u tekstu pitanja, odgovora i objašnjenja ispred znakova
  ~ = # { } : stavi \ ;
- između pitanja jedan prazan redak.
Vrati samo GIFT, u jednom bloku koda, bez objašnjenja.
JSON:
[ZALIJEPITE JSON]
```
