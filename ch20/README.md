# Poglavlje 20: Vlastiti asistent: upute, znanje i vještine

`asistent-5r_upute.md` je sustavska uputa Tomislavova „Asistenta za
5. razred“ (inačica 5, 38 redaka), a mapa `listic-u-tri-staze/` vještina iz
istog poglavlja: `SKILL.md` i u podmapi `references/` jedan izmišljeni
primjer ulaza i odobrenog izlaza. Ništa se ne pokreće. Uputu zalijepite u
polje za upute svojeg projekta ili asistenta i prilagodite je predmetu; za
vještinu mapu sažmite u ZIP ili učitajte samu datoteku `SKILL.md`, ovisno o
tome što vaš alat traži. Naziv mape mora ostati jednak polju `name`.
Datoteke znanja koje uputa spominje (`01_ishodi_MAT5.md` i ostale) pišete
sami, za svoj razred.
